# 07 2-stage shift register

Two one-bit stages chained through if/else (enable-gated).

From this directory:

```bash
vfpga verify design.v --tb design.tb --wave --open
```

From the repo root instead:

```bash
build/vfpga verify examples/tutorial/07_shift_register/design.v --tb examples/tutorial/07_shift_register/design.tb --wave --open
```
